# Better Auth Demo

A Next.js authentication demo based on the Web Dev Simplified Better Auth crash course. It exercises Better Auth with Postgres/Drizzle, email verification, password reset, social sign-in, passkeys, two-factor authentication, admin user management, organizations, and Arcjet protection on auth POST routes.

## Tech Stack

- Next.js 16 and React 19
- Better Auth with the Drizzle adapter
- PostgreSQL via Docker Compose
- Drizzle ORM and Drizzle Kit
- Tailwind CSS 4 and Radix UI components
- Resend for transactional email
- Arcjet for signup protection, bot checks, and rate limits

## Setup

Install dependencies:

```bash
npm install
```

Create a local environment file:

```bash
cp .env.example .env
```

At minimum, set:

- `DATABASE_URL`
- `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL`
- `ARCJET_API_KEY`
- `RESEND_API_KEY`

GitHub and Discord OAuth are optional, but their sign-in buttons only work when the matching client ID and secret are configured.

## Database

Start Postgres:

```bash
npm run db:start
```

Apply the schema:

```bash
npm run db:push
```

Useful database commands:

```bash
npm run db:generate
npm run db:migrate
npm run db:studio
npm run db:reset
```

`db:reset` is destructive and exits non-zero if the reset fails.

## Development

Run the app:

```bash
npm run dev
```

Open http://localhost:3000.

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
npm audit
```

There are currently no automated tests. Treat lint, typecheck, build, and manual auth-flow smoke tests as the baseline verification suite until tests are added.

## Notes

- `src/drizzle/schemas/auth-schema.ts` is the active schema export through `src/drizzle/schema.ts`.
- `src/drizzle/schemas/new-auth-schema.ts` is generated by `npm run auth:generate` for comparison before replacing the active schema.
- Avoid committing real `.env` files or provider secrets.
